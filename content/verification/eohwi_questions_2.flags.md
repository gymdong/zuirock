### #57 [어휘력/한자어 ★2 ox]
- 문제: '동병상련(同病相憐)'은 같은 병을 앓는 사람끼리 서로 불쌍히 여긴다는 뜻이다.
- 정답: O
- ⚠ codex 사실 확인 wrong: 해설은 ‘동병상련’을 서로 돕고 위로한다는 뜻으로 풀이하지만, 사전적 뜻은 같은 처지의 사람들이 서로 가엾게 여기는 것이다. 도움을 주는 행위까지 뜻하지는 않는다. (근거: 국립국어원 한국어기초사전 https://krdict.korean.go.kr/eng/dicSearch/SearchView?ParaWordNo=47179&nation=eng)

### #138 [어휘력/한자어 ★3.5 chosung]
- 문제: 한 치의 쇠붙이로도 사람을 죽일 수 있다는 뜻으로, 간단한 말로 남의 약점을 찔러 감동시키거나 당황하게 함을 이르는 사자성어는 무엇인가요? (네 글자)
- 정답: 촌철살인
- ⚠ codex 사실 확인 wrong: 문제의 뜻풀이가 ‘남의 약점을 찔러 감동시키거나 당황하게 함’으로 두 의미를 섞었습니다. 간단한 말로 남을 감동시키거나 남의 약점을 찌른다는 뜻입니다. (근거: 한국언론진흥재단 미디어교육 교재: https://www.meca.or.kr/api/communication/archive/download?attachFilePath=%2Freference%2Fboard%2FB0003%2F202205130542037271.pdf)

### #143 [어휘력/관용표현 ★3.5 chosung]
- 문제: 몹시 애를 먹거나 어려움을 겪는다는 뜻의 관용구 '○○을 치르다'의 빈칸에 들어갈 말은 무엇인가요? (두 글자)
- 정답: 홍역

### #155 [어휘력/관용표현 ★3.5 mcq]
- 문제: '한술 더 뜨다'의 뜻으로 알맞은 것은 무엇인가요?
- 정답: 이미 잘못된 일에 한 단계 더 나아가 엉뚱한 짓을 하다
- ⚠ codex 사실 확인 wrong: '한술 더 뜨다'는 남보다 말이나 행동의 정도가 더 심하다는 뜻이다. 잘못된 일이나 엉뚱한 짓에만 쓰이는 것으로 한정한 정답과 해설이 부정확하다. (근거: 국립국어원 한국어기초사전 https://krdict.korean.go.kr/eng/dicSearch/SearchView?ParaWordNo=85557)

### #160 [어휘력/맞춤법 ★3.5 mcq]
- 문제: "달리던 자전거가 자동차에 (   )."의 빈칸에 알맞은 말은 무엇인가요?
- 정답: 부딪혔다
- ⚠ codex 블라인드 답 불일치: 풀이 "부딪쳤다" ≠ 정답 "부딪혔다" (메모: 자전거가 자동차에 충돌했다면 ‘부딪쳤다’, 자동차에 치였다면 ‘부딪혔다’도 가능함.)
- ⚠ codex 사실 확인 ambiguous: 달리던 자전거가 자동차에 다가가 충돌했다면 '부딪쳤다', 자동차가 자전거를 들이받았다면 '부딪혔다'가 가능하다. 문장만으로 충돌 상황을 정할 수 없다. (근거: 국립국어원 온라인가나다 https://www.korean.go.kr/front/onlineQna/onlineQnaView.do?mn_id=261&pageIndex=1&qna_seq=312805)

### #170 [어휘력/맞춤법 ★4 chosung]
- 문제: 정성이 아주 지극하게라는 뜻의 부사로, '끔찍히'가 아닌 바른 표기는 무엇인가요? (세 글자)
- 정답: 끔찍이
- ⚠ codex 사실 확인 wrong: '정성이나 마음 등이 아주 지극하게'는 '간절히'의 뜻풀이이다. '끔찍이'는 '더할 수 없이 크고 대단하게' 등의 뜻이다. (근거: 국립국어원 한국어기초사전 https://krdict.korean.go.kr/eng/dicSearch/SearchView?ParaWordNo=14051&nation=eng ; https://krdict.korean.go.kr/eng/dicSearch/SearchView?ParaWordNo=38377&blockCount=30&currentPage=1&deleteWord_no=&lgCategoryCode=1&miCategoryCode=-1&myViewWord=60201&nation=eng&nationCode=6&searchFlag=Y&searchType=D&sort=C&syllablePosition=)

### #173 [어휘력/맞춤법 ★4 chosung]
- 문제: 아무런 뜻이나 생각 없이라는 뜻의 부사로, '무심고'가 아닌 바른 표기는 무엇인가요? (세 글자)
- 정답: 무심코

### #188 [어휘력/맞춤법 ★4 mcq]

### #240 [어휘력/한자어 ★4.5 mcq]

### #243 [어휘력/관용표현 ★4.5 mcq]
