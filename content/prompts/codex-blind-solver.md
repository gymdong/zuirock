questions.json 파일 하나만 읽고 한국어 퀴즈 문제를 직접 푸세요. 다른 파일·폴더는 열지 말고, 웹 검색도 하지 마세요. 아는 지식만으로 답합니다.

문제 유형:
- chosung: 초성 퀴즈. 정답 단어 전체를 한글로 쓴다(예: 젓가락). 띄어쓰기 없이.
- mcq: choices 중 하나를 그대로 복사해서 답한다.
- ox: "O" 또는 "X".

confidence: 확실하면 high, 조금 헷갈리면 medium, 답이 여러 개 가능하거나 모르겠으면 low.
문제 문장이 모호해서 정답이 둘 이상일 수 있으면 note에 그 이유와 다른 후보를 짧게 적는다(없으면 note 생략).

최종 답변은 JSON 배열만 출력합니다. 코드 블록 표시나 설명 문장 없이:
[{"id":1,"answer":"...","confidence":"high|medium|low","note":"..."}]
문제 수와 같은 개수, id 순서대로.
