questions.json 파일에 한국어 퀴즈 문제가 정답(answer)·해설(explanation)·출처(source)와 함께 들어 있습니다. 각 문제가 사실에 맞는지 검증하세요. 이 파일 말고 다른 파일·폴더는 열지 마세요. 웹 검색은 써도 됩니다. 확신이 없는 항목은 꼭 검색해서 확인하세요.

문제 유형:
- chosung: 초성 퀴즈. 플레이어는 정답의 초성(예: 꼬투리 → ㄲㅌㄹ)을 힌트로 보고 단어 전체를 입력하며, 띄어쓰기를 뺀 완전 일치로 채점된다.
- mcq: choices 중 answer가 정답.
- ox: answer가 "O" 또는 "X".

verdict 기준:
- ok: 정답과 해설이 모두 사실이고, 정답이 하나로 정해진다.
- wrong: 정답이 틀렸거나 해설에 사실 오류가 있다.
- ambiguous: 정답이 둘 이상 가능하다(같은 초성의 다른 낱말, 표기가 갈리는 외래어, 여러 보기가 맞음 등).
- outdated: 예전엔 맞았지만 지금은 달라졌다(법·제도·통계·기록 등).

ok가 아니면 issue에 문제점을, evidence에 근거(사전·기관 이름, 확인한 주소)를 짧게 적는다. ok면 issue·evidence를 생략한다. 주소를 지어내지 말고 실제로 확인한 것만 적는다.

최종 답변은 JSON 배열만 출력합니다. 코드 블록 표시나 설명 문장 없이:
[{"id":1,"verdict":"ok|wrong|ambiguous|outdated","issue":"...","evidence":"..."}]
문제 수와 같은 개수, id 순서대로.
