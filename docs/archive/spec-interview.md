### 문제 콘텐츠 (R1, R9, R16, R20)
- 시연 시점 문제 은행: MVP 4개 주제(상식·어휘력·역사·과학) × 약 150문제 = **약 600문제**. ★1~5 (0.5 단위) 전 구간, 고난도일수록 많은 역삼각형 구성
- 유형: 초성퀴즈 · 객관식(4지선다) · OX
- 세부 분야(고정): 상식 = 생활·사회·문화 / 어휘력 = 맞춤법·한자어·순화어 / 역사 = 한국사·세계사 / 과학 = 물리·화학·생물
- **문제 제작 흐름**: Claude API는 쓰지 않음. 개발 쪽이 **문제 JSON 형식과 생성 가이드**를 제공하면, 사용자가 Claude로 직접 문제를 만들어 JSON으로 전달 → **가져오기 스크립트/관리자 웹 업로드**로 '초안' 등록 → 검수자가 수정·승인해야 '공개'
- 문제 JSON 한 건의 형식:
  ```json
  {
    "topic": "과학", "subfield": "화학", "type": "chosung | mcq | ox",
    "difficulty": 3.5, "question": "...", "answer": "...",
    "choices": ["...", "...", "...", "..."],
    "explanation": "...", "source": { "title": "...", "url": "..." }
  }
  ```
  - `choices`는 객관식에만, 4개이며 정답을 포함. OX의 `answer`는 `"O"` 또는 `"X"`. 초성은 `answer`에서 자동 계산
- 가져오기 검사: 필수 필드, 난이도 0.5 단위·범위, 보기 4개와 정답 포함 여부, 기존 문제와 같은 문구인지. 오류는 몇 번째 문제인지와 이유를 보여주고, 통과한 문제만 초안으로 등록
- 관리자 웹: 미리 등록한 회원 계정만 접근. 문제 목록·수정·승인, 신고 처리, 난이도 보정 승인
- **초성 정답 판정**: 공백·문장부호를 무시하고 **완전히 일치할 때만 정답**. 허용 정답 목록은 두지 않음. 입력과 정답 중 한쪽이 다른 쪽을 포함하면 오답으로 처리하되, **입력한 사람에게만** "거의 비슷했어요!"를 보여주고 다시 입력할 수 있게 함
- 오류 신고: 해설 화면에서 신고, 근거(텍스트나 링크) 필수. 서로 다른 사용자의 신고가 3건 쌓이면 관리자가 확인할 때까지 출제 중지
- 난이도 보정: 풀이 30회 이상인 문제는 정답률 기반 추천 난이도를 보여주고, 관리자가 승인해야 반영
- 주제는 데이터로 관리. 문제가 없는 5개 주제(지리·예술·경제·철학·스포츠)는 주제 고르기(p4)와 방 만들기(p9)에 **'준비 중'으로 비활성 표시**. 문제가 추가되면 코드 변경 없이 열림

### 솔로 학습·주제 레벨 (R3, R10, R13, R19)
- **주제 레벨(Lv.1~99)은 솔로 스테이지 클리어로만 오름.** 대결·종합 세트는 주제 레벨에 영향을 주지 않음

- 스테이지 = 10문제 세트, **7개 이상 맞히면 클리어**. 못 깨면 같은 레벨에 다시 도전

- 새 주제 시작: ① 레벨테스트 ② 원하는 체크포인트의 기초 테스트 ③ Lv.1부터 중 선택

- 친구: 회원끼리만. 닉네임 검색이나 대결 결과 화면·프로필에서 신청하고 상대가 수락하면 친구. 친구 프로필(p16)에는 사진·캐릭터, 계정 레벨, 주제 레벨, 나와의 대결 전적 표시. 친구 삭제만 지원
- 대결 신청: 방을 만들고 친구의 **앱 내 초대함**에 초대를 보내면서, 공유용 **초대 링크**도 함께 만듦

### 성장 시스템 (R2, R3, R10, R12, R13, R17)
- 문제별 XP = (난이도 × 10) × 보너스 배율(노힌트 +20%, 취약 주제 정답·오답노트 복습 성공 +50%) × 같은 문제 감쇠(7일 안 2번째는 50%, 3번째부터는 0). 합계를 낸 뒤 마지막에 **일일 상한 3,000**으로 자름
- 계정 XP 지급 시점:
  - 솔로 스테이지: **처음 클리어할 때만** 지급. 실패하거나 이미 클리어한(건너뛴 것 포함) 스테이지는 0
  - 종합 세트 · 오늘의 3분 지식 · 약점 퀘스트: 10문제 중 7개 이상일 때만. 3분 지식은 하루 1회만
  - 레벨테스트 · 기초 테스트: XP 없음
  - 대결: 대결이 끝났을 때 정답 XP + 순위 보너스(1위 +15, 2위 +10, 3위 +5). 같은 멤버로 1시간 안에 다시 하는 방은 XP 50%
- 일일 상한에 도달해도 클리어와 레벨업은 정상으로 되고 XP만 0. 결과에 '오늘 XP 상한 도달' 표시
- 계정 레벨업 필요 XP = 100 × 현재 레벨. 계정 레벨은 상한 없음
- 스트릭: 솔로 10문제 세트를 끝까지 풀거나(클리어 여부 무관) 대결을 끝까지 참여하면 그날 인정. 3·7·14·30일에 치즈 10·30·50·100
- 치즈: 스트릭 보상으로만 받음(실제 결제 없음)
- 보호권: 50치즈, 최대 2개 보유. 다음 날 00:00(KST)에 판정하면서 자동 사용. 복구: 끊긴 다음 날 안에 100치즈
- 캐릭터: 부위 5개(모자·상의·하의·신발·소품)를 전신 몸 위에 레이어로 겹쳐 그림. 아이템 이미지는 데이터로 관리(파일만 바꾸면 그림이 바뀜). 시연용 아이템은 부위당 4개 = 기본 1, 치즈 구매 2(80·150), 레벨 해금 1(Lv.20). 없는 아이템도 미리 입어볼 수 있음. 꾸미기는 점수에 영향 없음

### 학습 데이터 (R7, R8, R15)
- 풀이 로그: 주인(회원 ID 또는 게스트 임시 ID), 문제, 정답 여부, 응답 시간, 초성 공개 전 정답 여부, 시각, 모드(스테이지·종합·3분 지식·퀘스트·레벨테스트·기초 테스트·대결)
- 주간 리포트(월~일, p12): 매주 월요일 00:00(KST)에 지난주 리포트를 확정. 이번 주 진행 중인 수치도 바로 볼 수 있음. 내용은 푼 문제 수, 정답률, 연속 학습, 주제별 정답률과 지난주 대비, '가장 많이 늘었어요'(10문제 이상 푼 주제 중 정답률 상승 폭이 가장 큰 주제)
- 약점 3가지: 세부 분야 단위. 5문제 이상 푼 분야 중 오답률 순으로 뽑고, 이유(오답률·응답 시간·오답노트 문제 수)를 한 줄로 표시
- 약점 집중 퀘스트: 약점 분야 10문제 세트, 7개 이상이면 +50 XP, 주 1회
- 데이터 부족: 주간 풀이 30문제 미만이면 '아직 데이터가 부족해요'와 첫 진단 세트(내 주제별 5문제)
- 전체 기록 탭: 누적 문제 수·정답률, 최장 스트릭, 대결 전적, 월별 학습량, 주제별 누적
- 오답노트: 틀린 문제는 자동으로 저장되고, 복습에서 한 번 맞히면 '복습 완료'. 해설과 함께 다시 볼 수 있음
- 기록 삭제: 프로필 > 로그인 계정 관리에서 '학습 기록 전체 삭제'(풀이 로그·오답노트·리포트 삭제, 레벨·XP 초기화)와 '회원 탈퇴'(모든 데이터 삭제)
- 시연 데이터: 데모 계정에 **4주 치 가상 풀이 로그**를 넣는 시드 스크립트(치즈 320, 친구, 대결 전적 포함). 시드 로그도 실제 계산 로직을 그대로 통과함

## Non-Goals (MVP 제외)

- 친구 차단·신고
- 지리·예술·경제·철학·스포츠 문제 은행(화면에는 '준비 중'으로 표시)
- 최종 캐릭터 그림체·아이템 에셋(임시 에셋 사용)

- 솔로 제한 시간

## Acceptance Criteria

### 실시간 퀴즈방
- [ ] AC-M1: 방장이 정한 조건(주제·유형·최저 난이도)을 출제된 모든 문제가 만족하고, 한 대결 안에 중복이 없으며, 모든 참가자가 같은 순서로 받는다
- [ ] AC-M2: 조건에 맞는 문제가 M개(< 설정한 문제 수)이면 확인 창이 뜨고, 동의하면 M문제로 진행된다
- [ ] AC-M3: 4자리 코드·초대 링크·초대함으로 입장할 수 있다. 9번째 참가자와 대결 시작 후의 입장은 거부된다. 같은 닉네임에는 숫자가 붙는다
- [ ] AC-M4: 2명 이상이고 방장을 뺀 전원이 준비해야 시작할 수 있다. 30분 동안 시작하지 않으면 방이 해산된다
- [ ] AC-M5: 정답 점수가 100 + floor(남은 시간 비율 × 50)이고, 초성 공개 전 정답이면 +30이다. 서버 시간으로 계산한다
- [ ] AC-M6: 객관식·OX의 두 번째 제출은 거부된다. 초성은 여러 번 제출할 수 있고, 포함 관계인 입력에는 본인에게만 "거의 비슷했어요!"가 보인다
- [ ] AC-M7: 모두 제출하거나 시간이 끝나면 정답과 해설이 3초 표시되고 다음 문제로 넘어간다
- [ ] AC-M8: 재접속하면 현재 문제부터 이어지고, 놓친 문제는 0점이다. 방장이 나가도 대결이 끝까지 진행된다
- [ ] AC-M9: 순위가 점수 → 정답 수 → 총 응답 시간 순으로 매겨진다
- [ ] AC-M10: 결과 화면에 순위·점수·정답 수·XP가 나오고, 회원의 오답은 오답노트에 들어가며, 모든 제출이 풀이 로그에 저장된다. 게스트에게는 '로그인하고 기록 저장하기'가 보인다
- [ ] AC-M11: '한 판 더'를 누르면 같은 설정·같은 코드의 대기실로 돌아간다

### 솔로 학습·주제 레벨
- [ ] AC-S1: 7/10 이상이면 주제 레벨이 1 오르고, 6/10 이하면 그대로다
- [ ] AC-S2: 출제 난이도가 레벨 구간표 범위 안에 있다
- [ ] AC-S3: 레벨테스트가 ★2.5에서 시작해 ±0.5씩 15문제로 진행되고, 마지막 5문제 평균이 배치표대로 레벨로 바뀐다. 시작 레벨을 확인하는 단계가 있다
- [ ] AC-S4: 기초 테스트에서 8/10 이상이면 그 체크포인트로 이동하고, 건너뛴 스테이지는 클리어로 처리된다(다시 해도 XP 0). 불합격이면 진행이 그대로다
- [ ] AC-S5: 솔로에는 타이머가 없다. 힌트 버튼을 누르지 않고 맞히면 노힌트 보너스가 붙는다
- [ ] AC-S6: 솔로 세트마다 오답노트 문제가 최대 2개 섞인다
- [ ] AC-S7: 종합 세트에서 오답률 상위 2개 주제가 약 50%를 차지한다
- [ ] AC-S8: 대결이나 종합 세트를 해도 주제 레벨은 변하지 않는다
- [ ] AC-S9: 빈 홈(p3), 고른 주제만 표시, '+ 주제 추가'가 항상 보이고, 문제가 없는 주제는 '준비 중'으로 비활성이다

### 계정·게스트·프로필
- [ ] AC-A1: 카카오·네이버·Google 로그인이 배포 도메인에서 실기기로 동작하고, JWT로 API에 접근할 수 있다
- [ ] AC-A2: 게스트가 결과 화면에서 로그인하면 그 임시 ID의 풀이 로그가 모두 계정으로 옮겨지고, XP는 어뷰징 규칙을 적용한 값으로 다시 계산된다
- [ ] AC-A3: 한 번 병합된 임시 ID는 다른 계정에 다시 병합할 수 없다. 병합하지 않은 게스트 기록은 30일 뒤 삭제된다
- [ ] AC-A4: 닉네임은 최대 10자이고, 중복이면 저장할 수 없다. 프로필 사진은 세 가지 출처 중에서 고를 수 있다
- [ ] AC-A5: 친구 신청과 수락 후 양쪽 목록에 서로 표시되고, 삭제하면 양쪽에서 사라진다
- [ ] AC-A6: 친구 프로필에 캐릭터·계정 레벨·주제 레벨·나와의 전적이 표시된다
- [ ] AC-A7: 대결 신청을 누르면 방이 생기고, 친구의 초대함에 초대가 보이며, 초대 링크가 만들어진다
- [ ] AC-A8: 초대 링크가 앱이 없는 휴대폰 브라우저에서는 웹으로, 앱이 설치된 기기에서는 앱으로 열린다

### 성장 시스템
- [ ] AC-G1: 계정 XP가 (난이도 × 10) × 보너스 × 감쇠 → 합계 → 일일 상한 순서로 계산되고, XP 이력에 사유와 함께 기록된다
- [ ] AC-G2: 실패한 스테이지, 이미 클리어했거나 건너뛴 스테이지, 레벨테스트·기초 테스트는 XP가 0이다
- [ ] AC-G3: 종합·3분 지식·퀘스트는 7/10 이상일 때만 XP를 주고, 3분 지식은 하루 1회만 준다
- [ ] AC-G4: 일일 상한에 도달한 뒤에도 스테이지 클리어와 레벨업은 정상으로 되고, '상한 도달'이 표시된다
- [ ] AC-G5: 레벨업에 100 × 현재 레벨 XP가 필요하고, 계정 레벨에는 상한이 없다
- [ ] AC-G6: 스트릭이 인정 조건(솔로 10문제 완주 또는 대결 완주)대로 쌓이고, 3·7·14·30일에 치즈가 지급된다
- [ ] AC-G7: 보호권이 00:00(KST) 판정 때 자동으로 사용되고, 다음 날 안에 100치즈로 복구할 수 있다
- [ ] AC-G8: 캐릭터 5개 부위를 착용하고 저장할 수 있다. 가지지 않은 아이템은 미리 입어볼 수만 있다. 치즈 구매(80·150)와 Lv.20 해금이 동작한다
- [ ] AC-G9: 아이템 이미지 파일을 바꾸면 코드 변경 없이 그림이 바뀐다

### 학습 데이터
- [ ] AC-D1: 모든 모드의 모든 제출이 정해진 필드를 갖춘 풀이 로그로 저장된다
- [ ] AC-D2: 주간 리포트의 수치가 풀이 로그를 KST 기준 월~일로 집계한 값과 일치한다. 월요일 00:00에 확정되고, 이번 주 수치도 볼 수 있다
- [ ] AC-D3: 약점 3가지가 '5문제 이상 푼 세부 분야 중 오답률 순'으로 뽑히고 이유가 표시된다
- [ ] AC-D4: 주간 풀이가 30문제 미만이면 '데이터가 부족해요'와 진단 세트가 표시된다
- [ ] AC-D5: 약점 퀘스트에서 7/10 이상이면 +50 XP가 지급되고, 주 1회만 받을 수 있다
- [ ] AC-D6: 오답노트에 틀린 문제가 자동으로 들어가고, 복습에서 맞히면 '복습 완료'가 된다
- [ ] AC-D7: '학습 기록 전체 삭제'와 '회원 탈퇴'가 정의한 범위대로 데이터를 지운다
- [ ] AC-D8: 시드 스크립트를 실행하면 데모 계정의 리포트·스트릭·전적·친구·치즈가 채워지고, 그 값이 실제 계산 로직과 일치한다

### 문제 콘텐츠
- [ ] AC-C1: 문제 JSON 형식 문서와 생성 가이드(Claude에 넣을 입력 템플릿)가 제공된다
- [ ] AC-C2: 가져오기가 필수 필드·난이도 단위·보기·중복을 검사하고, 오류를 문제 번호와 이유로 알려주며, 통과한 문제만 초안으로 등록한다
- [ ] AC-C3: 초안이나 검수 완료 상태의 문제는 출제되지 않는다. 관리자가 승인하면 공개된다
- [ ] AC-C4: 관리자 웹에는 등록된 계정만 접근할 수 있고, 문제 목록·수정·승인, 신고 처리, 난이도 보정 승인이 동작한다
- [ ] AC-C5: 초성 판정에서 공백·문장부호 차이만 있으면 정답이다. 포함 관계인 입력은 오답이면서 본인에게만 근접 안내가 보인다
- [ ] AC-C6: 근거가 없는 신고는 거부된다. 서로 다른 사용자의 신고가 3건 쌓이면 출제가 중지된다
- [ ] AC-C7: 풀이 30회 이상인 문제에 추천 난이도가 표시된다
- [ ] AC-C8: 주제 데이터에 문제가 추가되면 '준비 중' 주제가 코드 변경 없이 열린다

### 시연 시나리오 (전체)
- [ ] AC-E2E: (배포 환경, 실기기) 회원 A가 앱에서 방을 만들고, 게스트 B가 다른 휴대폰 브라우저에서 링크로 입장해 대결한다. B가 결과 화면에서 로그인하면 기록이 병합된다. A의 XP와 오답노트가 갱신되고, 리포트 탭의 이번 주 수치와 약점이 그 대결을 반영하며, 종합 세트에서 약점 주제가 더 많이 출제된다
